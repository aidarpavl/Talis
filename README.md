# 📊 TALIS сауалнамасы — талдау көмекшісі

Мұғалімдердің TALIS сауалнамасына берген жауаптарын талдайтын Streamlit веб-қосымшасы.

## Не істейді

1. **📝 Google Форманы ашу** батырмасы сауалнама формасын ашады.
2. **📊 Google Таблицаны ашу** батырмасы форма жауаптарын Google Таблицадан жүктеп, веб-парақта **кесте ретінде** көрсетеді (іздеу бар).
   Қаласаңыз, жауаптарды CSV / Excel файл ретінде де жүктеуге болады.
3. **Талдау жасайды:**
   - респонденттер құрамы (жынысы, жасы, өтілі, білімі, жұмыспен қамтылуы);
   - әр сұрақ бойынша жауаптардың бөлінуі, оң жауап үлесі, орташа балл;
   - **TALIS бағыттары бойынша индекс (0–100)**: кәсіби даму, кері байланыс, бағалау жүйесі, ынтымақтастық,
     жұмысқа қанағаттану және мектеп климаты, басшылық, белсенді оқыту әдістері, сынып тәртібі;
   - топтарды салыстыру (өтілі, жасы, жынысы бойынша; топта кемінде 5 респондент болса);
   - **графиктер** (бағыттар индексі, құрамы, әр кестелік сұрақ бойынша 100% бағаналы диаграммалар);
   - **SWOT**: мектептің күшті жақтары, әлсіз жақтары, даму мүмкіндіктері және қауіптері.
4. **ChatGPT талдауы** — бағдарлама барлық деректерді қосып промпт дайындайды:
   - 💬 **тегін**: промптты көшіріп chatgpt.com-ға қоясыз, жауабын қайта қосымшаға қоясыз;
   - 🤖 **автоматты**: OpenAI API кілті болса, батырманы басқанда ChatGPT өзі талдайды.
5. **Есепті жүктеу**: **Word (.docx)** — аналитикалық анықтама (кестелер, графиктер, SWOT, ChatGPT талдауы) және
   **Excel (.xlsx)** — жауаптар, сұрақтар статистикасы, бағыттар, SWOT, графиктер, талдау мәтіні.

## Google Таблицаны дайындау (міндетті)

Таблица веб-парақта көрінуі үшін Google Таблицада: **Настройки доступа / Бөлісу → «Все, у кого есть ссылка» /
«Сілтемесі бар кез келген адам» → Читатель / Оқырман**. Әйтпесе бағдарлама таблицаны оқи алмайды.

Ескерту: сілтемесі бар адам жауаптарды көре алады. Сауалнамада аты-жөні сұралмайтынына көз жеткізіңіз
(TALIS анонимді сауалнама).

## GitHub-қа сақтау және Streamlit-те веб-парақ ретінде ашу

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `talis-analysis`).
2. **Add file → Upload files** арқылы осы папкадағы барлық файлды жүктеңіз:
   `app.py`, `requirements.txt`, `README.md`, `.gitignore` және `.streamlit` папкасы → **Commit changes**.
3. [share.streamlit.io](https://share.streamlit.io) сайтына GitHub арқылы кіріп, **Create app** → репозиторий,
   `main` тармағы, `app.py` файлы → **Deploy**.
4. Бірнеше минуттан кейін қосымша `https://….streamlit.app` сілтемесімен ашылады.

### Secrets (міндетті емес)

Streamlit → **App settings → Secrets**:

```toml
OPENAI_API_KEY = "sk-..."      # ChatGPT автоматты режимі үшін (platform.openai.com → API keys)
SCHOOL_NAME = "Мектеп атауы"   # есептің басына жазылады
# FORM_URL = "..."  SHEET_URL = "..."  — басқа форма/таблица қолдансаңыз
```

OpenAI API ақылы (ChatGPT Plus жазылымына кірмейді). Тегін режим кілтсіз жұмыс істейді.

## Өз компьютерде іске қосу

```bash
pip install -r requirements.txt
streamlit run app.py
```
